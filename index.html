App Info / Handoff Guide
What This App Is

The Herd Health Ledger is a cattle management app built for Farnan Cattle Company — cow records, medical logs, calving, breeding, herd tallies, bulls, haying, equipment, and reporting.

How It's Built

It's a single HTML file — no app store, no install, no build process. It runs entirely in a web browser. Data is stored in a separate database service (Supabase), not inside the file itself.

Where Things Live

Live app: farnanjeff-mark.github.io/Herd-Med-Log/
Code (GitHub): github.com/farnanjeff-mark/Herd-Med-Log, file index.html
Database (Supabase): project at nuutfigyhjyqhtxotuln.supabase.co

Making a Change

Someone (a developer, or an AI coding assistant like Claude) edits index.html, then: download the file → replace it in the GitHub repo → commit → wait for the green checkmark under the repo's "Actions" tab → the live site updates automatically within a minute or two.

You Can Manage Yourself (No Code Needed)

These have their own "+ Add" and remove buttons right in the app:

• Bulls — Utilities → Manage Bulls
• Haying Fields — Utilities → Manage Haying Fields
• Medicines — Utilities → Manage Meds
• Locations — Utilities → Manage Locations
• Owners — Utilities → Manage Owners
• Groups — Utilities → Manage Groups
• Reasons — Utilities → Manage Reasons
• Equipment — Farm Operations → Equipment
• Herd Tally Locations — Farm Operations → Herd Tally
• Text Recipients — Utilities → Text a List → Manage Recipients

Still Needs a Developer to Change

Status (Active/Sold/Deceased), Herd Season (Spring/Fall), Birth Assist, and Pregnancy Method are built into the code on purpose — the app's logic depends on those exact values, so they're not offered as self-editable lists. Changing these requires editing index.html directly.

Database Migrations

Some changes need a small SQL script run in the Supabase dashboard (SQL Editor) before the matching app update will work — these are numbered files like migration-v29-bulls-table.sql. Always run any pending migration before using a feature that depends on it.

Access Needed to Maintain This App

Whoever takes this over will need to be added as a collaborator on the GitHub repo, and given access to the Supabase project (or the login credentials for both). Without that access, this document alone won't be enough — make sure a trusted person actually has a way in, not just this explanation of how things work.
